# UrbanShop — Demo internet-do‘kon

HTML, CSS va Vanilla JavaScript asosida tayyorlangan responsive e-commerce demo.

## Ishga tushirish
1. `urbanshop` papkasini kompyuterga oching.
2. `index.html` faylini brauzerda oching yoki VS Code'da **Live Server** bilan ishga tushiring.
3. Internet ulanishi bo‘lsa, Google Fonts va mahsulot rasmlari yuklanadi.

## Fayllar
- `index.html` — sayt tuzilishi
- `style.css` — dizayn, dark/light mavzu va responsive qoidalar
- `script.js` — mahsulotlar, qidiruv, kategoriya filtri, saralash, savatcha, sevimlilar va demo obuna

## Ishlaydigan funksiyalar
- Dark / Light Mode (tanlov brauzerda saqlanadi)
- Mahsulot qidiruvi
- Kategoriya bo‘yicha filtrlash
- Narx va reyting bo‘yicha saralash
- Mahsulot tafsilotlari modal oynasi
- Savatchaga qo‘shish, miqdorni o‘zgartirish va o‘chirish
- Sevimlilarga qo‘shish
- LocalStorage orqali savatcha va sevimlilarni saqlash
- Mobil menyu va responsive layout
- Demo obuna formasi

## Muhim
Bu frontend demo: haqiqiy login, server, ma’lumotlar bazasi, to‘lov yoki buyurtma yuborish mavjud emas. Mahsulotlar va narxlar namuna uchun. Haqiqiy loyiha uchun backend/API, server-side validation va xavfsiz to‘lov provayderi alohida ulanishi kerak.
